# Subagents - IMPORTANT
Use as many subagents as possible to work in parallel.
Not all your subagents should be Opus 5. Use Haiku and Sonnet with adequate effort for simpler tasks. 
Always select the cheapest model/effort possible to do the task but the task MUST be
done correctly so selected model still must be able to complete the work correctly. The quality is more important. The cost goes second.
IMPORTANT! Use local LLM Qwen 3.8 as much as possible but be aware it's slow and you have to give it short tasks and check its progress.
